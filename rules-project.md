Версия v1.8. Работает совместно с rules-common.md. Универсальные правила выше правил этого файла (см. правило 9.2 в rules-common.md).

## 1. Название и назначение

- Название: Разделитель текста по меткам (text-separator).
- Назначение: одностраничный HTML-инструмент, который по загруженному текстовому файлу с метками вида `<!-- FILE: имя -->` нарезает текст на отдельные plain-text файлы и упаковывает их в ZIP-архив для скачивания.
- Пользователь результата: пользователь, у которого есть текст с такими метками и который хочет получить набор файлов без ручного копирования.

## 2. Адрес репозитория

- Адрес: `https://github.com/butko/text-separator`.
- Проект опубликован, заглушка не используется.

## 3. Стек и среда

- Язык и версия: HTML5 + JavaScript (ES2017+, без сборки и транспиляции).
- Внешние библиотеки: JSZip 3.10.1, подключается через CDN (cdnjs.cloudflare.com).
- Платформа запуска: современный браузер (Chrome, Firefox, Edge, Safari последних версий). Работает локально, без сервера. Дополнительно развёрнут на GitHub Pages: `https://butko.github.io/text-separator/index.html`.
- Ограничения целевой среды: чтение файла целиком в память (`FileReader.readAsText`); для файлов свыше ~200–300 МБ может потребоваться потоковая обработка через `Blob.slice()` — при необходимости дорабатывается.
- Способ установки зависимостей: не применимо при работе через CDN; для офлайн-режима JSZip кладётся локально рядом с `index.html`.

## 4. Схема работы

- Вариант (по правилу 6.6): отдельный файл с изображением — SVG, имя файла `scheme.svg`.
- В `readme.md` вставляется через markdown-синтаксис изображения с осмысленным alt-текстом.
- `scheme.svg` входит в перечень файлов проекта (раздел 5) с активной ссылкой.
- Причина выбора: встроенная Mermaid-схема в `.md` при оформлении по правилу 2.1 (отступ в 4 пробела) на GitHub отображается как код, а не как диаграмма. Тройные обратные кавычки с меткой `mermaid` нарушили бы 2.1 и сломали бы копирование файла из чата целиком. Отдельный SVG устраняет конфликт: схема отрисовывается везде, а `readme.md` копируется одним блоком.
- Проверка актуальности: при изменении логики программы SVG читается как текст (2.2) и сравнивается с кодом по 6.12.

## 6. Команды запуска

- Онлайн: открыть в браузере `https://butko.github.io/text-separator/index.html`.
- Локально: открыть `index.html` в браузере (двойной клик по файлу или «Файл → Открыть» в браузере).
- Локальный веб-сервер не требуется ни в одном из вариантов.

## 7. Правила, специфические для проекта

- Все данные обрабатываются локально в браузере; на сервер ничего не отправляется.
- Кодировка исходного текста — UTF-8 (`FileReader.readAsText`).
- Имя фрагмента берётся из метки `<!-- FILE: имя -->`; при совпадении имён из разных входных файлов к последующим добавляется суффикс `_2`, `_3` и т. д.
- Текст до первой метки игнорируется; текст после последней метки считается содержимым последнего фрагмента.
- Можно загружать несколько исходных файлов одновременно; все найденные фрагменты упаковываются в один ZIP.

## 8. Ограничения проекта

- Размер исходного текста ограничен памятью браузера (практически — сотни МБ).
- Поддерживаются только текстовые файлы.
- Работает только в браузере; Node.js не используется.
